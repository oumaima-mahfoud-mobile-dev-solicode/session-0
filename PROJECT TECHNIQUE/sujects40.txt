#PROMPT :
  Donne-moi **40 idées de projets de bases de données** pour un exercice de modélisation relationnelle.

### Contraintes obligatoires :

* Chaque projet doit contenir **exactement 3 tables**.
* Les 3 tables doivent représenter :

  1. Une entité qui joue le rôle de **personne/utilisateur principal**
  2. Une table de **catégories**
  3. Une table de **contenus/articles**
* Le nom des 3 table doit êtreS **adapté au rôle de la personne dans le projet**. 

  * Exemple : `students`, `categories`, `articles`
  * Exemple : `chefs`, `categories`, `recipes`
  * Exemple : `coaches`, `categories`, `articles`
 
* **Ne mets pas obligatoirement `users`**.
* Ne considère pas automatiquement la personne comme un `client`.
* Le nom de la table de contenu doit également être adapté au projet : `articles`, `recipes`, `courses`, `news`, `reviews`, `guides`, etc.
* La table `categories` doit rester présente et servir à classer les contenus.
* Chaque projet doit avoir une relation logique entre les 3 tables.
* Les 40 projets doivent être **très différents les uns des autres**.

* Les projets doivent rester simples et réalisables par un étudiant.
* Aucun projet ne doit nécessiter une 4ème table.

### Pour chaque projet, donne exactement :

**1. Nom du projet :**
**Concept :**
**Table 1 :** nom de la table + rôle
**Table 2 :** `categories` + rôle
**Table 3 :** nom de la table de contenu + rôle
**Relations :** expliquer simplement les relations entre les 3 tables
**Exemple :** donner un exemple concret de données.

### Exemple du niveau attendu :

**Projet : Plateforme de recettes de cuisine**

* `chefs` → contient les informations des chefs qui publient les recettes.
* `categories` → Cuisine marocaine, pâtisserie, cuisine rapide, etc.
* `recipes` → contient les recettes publiées.
* Relation : un chef peut publier plusieurs recettes et une catégorie peut contenir plusieurs recettes.

**Projet : Plateforme de cours**

* `teachers` → contient les enseignants.
* `categories` → programmation, design, marketing, etc.
* `courses` → contient les cours publiés.
* Relation : un enseignant peut créer plusieurs cours et une catégorie peut contenir plusieurs cours.

Maintenant, génère **40 projets différents**, en respectant strictement ces règles.
